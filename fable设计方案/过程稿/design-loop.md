# 裁决闭环循环:最强可执行版设计(循环最大化派)

> 对应简报:《DEGRADE设计简报-loop方案.md》。立场:裁决闭环方向正确,树该砍。本文给出它在 **3–8 次调用**硬约束下仍然成立的最强版本,并诚实标出它会在哪里死、以及"证明不了就退回 best-of-N"的预注册杀死开关。

---

## 0. 核心主张(一段话)

树的罪不是"搜索",而是**假装用信号决策**。循环的价值不是"多迭代",而是**把每一次调用都变成裁决的确定性函数**。在 3–8 次调用的尺度下,循环的形态必须彻底改变:没有收敛耐心、没有多轮退火,只有**一张确定性决策表 + 三条便宜/昂贵动作 + 单事件停止**。关键资源洞察:**种子候选的生成成本已沉没,裁决一条种子只花 1 次调用,而任何新候选(加宽或加深)都花 2 次**。因此循环的本质赌注是:**"1 次裁决制导的定向动作(2 调用)"能否胜过"2 条免费种子的裁决抽签(2 调用)"**。本设计让这个赌注变得可测量、可预注册、可被否证——如果否证,系统一键退化为"种子感知 best-of-N + 裁决触发停止",不丢任何已有便宜收益。

---

## 1. 预算会计学(一切设计的地基)

动作与成本(每次 LLM 调用 30–90 秒):

| 动作 | 成本 | 说明 |
|---|---|---|
| `JUDGE_SEED` | 1 | 裁决一条未裁决的初稿种子(生成已沉没,**半价加宽**) |
| `REJUDGE` | 1 | 裁决未解析时重裁一次(每候选限 1 次) |
| `CROSS_EXAM` | 1 | 异源(不同模型或至少不同对抗人设+温度)critic 复核准冠军;仅 B≥6 预留 |
| `DEEPEN` | 2 | 针对 best 的最强反驳生成精修版 + 裁决 |
| `SHARPEN` | 2 | 针对"证据不足"生成证伪条件具体化版 + 裁决(DEEPEN 的变体) |
| `WIDEN_NEW` | 2 | 携带角度排除清单生成新角度候选 + 裁决 |

预算 B ∈ [3,8] ⇒ 定向动作(2 调用)最多 1–4 个。**结论:任何"多轮收敛"叙事在这个尺度是幻觉,设计必须按"1–4 次定向出手"来做。**

各 B 的静态配置:

| B | CROSS_EXAM 预留 | 深化链深度上限 | 最坏情况(全致命) | 典型轨迹举例 |
|---|---|---|---|---|
| 3 | 0 | 1 | 3×JUDGE_SEED | J → DEEPEN |
| 4 | 0 | 1 | 4×J | J, J → DEEPEN |
| 5 | 0 | 1 | 5×J | J → DEEPEN → J, J |
| 6 | 1 | 2 | 5×J + 复核 | J → DEEPEN → SHARPEN → 复核 |
| 7 | 1 | 2 | 6×J + 复核 | J, J → DEEPEN → WIDEN → 复核 |
| 8 | 1 | 2 | 7×J + 复核 | J, J → DEEPEN → DEEPEN² 或 WIDEN → 复核 |

## 2. ① 控制流(伪代码,含逐步调用计数)

```text
输入: seeds[]        # 初稿产出的若干候选,生成成本沉没
      B ∈ [3,8]     # 额外调用预算
状态: P = []         # 已裁决池: (候选, 裁决, 分, 血统, 门标记)
      Q = seeds     # 未裁决队列(按初稿输出顺序,确定性)
      b = B
      reserve = 1 if B >= 6 else 0        # 异源复核预留
      ledger = []   # 台账:每步动作、裁决、调用数、门判定、丢弃原因

# ---- 引导:裁决第一条种子 ----
judge(Q.pop())                             # b -= 1

# ---- 主循环 ----
while true:
    best = argmax_score(P)                 # 平分并列:创建更早者胜(禁用任何计数型 tie-break,见铁律检验)
    act  = DECIDE(best, P, Q, b - reserve) # 第 3 节的确定性决策表
    if act == STOP: break
    execute(act)                           # 按上表扣 b;新候选过机械门(第 5 节)后入池;全部记台账

# ---- 收尾 ----
if reserve == 1 and b >= 1:
    CROSS_EXAM(argmax_score(P))            # b -= 1;终分 = min(本源裁决分, 异源裁决分)
finish():
    top-K = 按终分排序
    分 < 0.35 的条目在产物中强制标注「未站住」;若全池如此,产物如实输出「本轮无站住候选」
    「证据不足+可证伪」的存活者单列「探索性前沿」轨道,与「站住候选」分轨呈现
    ledger 全量落盘:动作序列、裁决序列、每门判定、丢弃与浪费调用数、停止原因码
```

调用计数不变式:`Σ(动作成本) + 引导1 + 复核(0或1) == B - 剩余b`,由台账逐条核对,产物中打印。

## 3. ③ 宽/深决策表(裁决 → 动作,纯确定性,无任何抽样)

`b` 指扣除复核预留后的可用调用。`可深化(x)` ≡ depth(x) < 深度上限 ∧ x 未被标记 deepen_exhausted ∧ x 的深化次数 < 1。

| best 的裁决 | 分 | 依序尝试的动作(取第一个满足条件者) | 理由 |
|---|---|---|---|
| 无法反驳 | 0.85 | ① 若强候选数(≥0.70) < K 且 Q≠∅ 且 b≥1 → `JUDGE_SEED`;② 否则 **STOP(S1)** | 无缺陷可修,深化无靶点;只用半价动作补 K 位,然后省钱停 |
| 轻微 | 0.70 | ① b≥2 且 可深化 → `DEEPEN`;② Q≠∅ 且 b≥1 → `JUDGE_SEED`;③ STOP | 小缺陷+critic 点名了靶点:0.70→0.85 是全系统期望增益最高的 2 调用。这正是简报要保留的"针对最强反驳的一遍精修" |
| 证据不足+可证伪 | 0.68 | ① 未 SHARPEN 过 且 b≥2 → `SHARPEN`;② 已 SHARPEN 且存活 → **STOP(S2, 前沿)**;③ Q≠∅ 且 b≥1 → `JUDGE_SEED`;④ STOP | 见第 7 节问题 1 的直答 |
| 未解析 | 0.50 | ① 重裁次数=0 且 b≥1 → `REJUDGE`;② 否则按 0.45 行处理 | 解析失败先用机械正则兜底解析,仍失败才花 1 调用 |
| 证据不足−无证伪条件 | 0.45 | ① 未 SHARPEN 且 b≥2 → `SHARPEN`;② Q≠∅ 且 b≥1 → `JUDGE_SEED`;③ b≥2 → `WIDEN_NEW`;④ STOP | 缺证伪条件恰是 SHARPEN 的直接靶点 |
| 严重 | 0.35 | ① Q≠∅ 且 b≥1 → `JUDGE_SEED`;② b≥2 且 可深化 → `DEEPEN`;③ b≥2 → `WIDEN_NEW`;④ STOP | 修大缺陷先验成功率低(树的 24 次深化 0 夺冠是警告);半价抽一条新种子在期望上占优 |
| 致命 / 全池皆致命 | 0.00 | ① Q≠∅ 且 b≥1 → `JUDGE_SEED`;② b≥2 → `WIDEN_NEW`(带角度排除清单);③ STOP(S4) | 死马不医;先耗尽免费宽度,再买新宽度 |

要点:**宽/深完全由 best 的裁决分级驱动,决策表是确定性函数**——这就是对树"抛硬币"的直接反命题,且可用反事实重放机械验证(见 M-A1)。

## 4. ② 停止条件(全部单事件触发,零模型自评,零耐心计数)

- **S1 站住即停**:champion 裁决 = 无法反驳(K 位已满时)。
- **S2 前沿即停**:champion = 证据不足+可证伪,且已经过 SHARPEN 后的**第二次独立裁决**仍无证据可攻。标注为"探索性前沿"分轨输出。
- **S3 预算耗尽**:b(扣预留)< 当前任何被允许动作的最低成本。
- **S4 无路可走**:Q 空 ∧ 所有候选 deepen_exhausted ∧ b<2。
- 停止原因码写入台账与产物。

**直答简报问题 2:"连续两轮无更优"在此预算下是死条款。** 耐心=2 需要在峰值后再花 2 轮 = 4 次调用来"确认停滞",占 B=8 的 50%、B≤5 的 ≥80%;B=3(仅 1 轮)下**数学上不可能触发**,必然退化为"固定跑满"。所以本设计彻底不用耐心计数,用上面四个**单事件、裁决触发**的停止条件替代。这不依赖模型自评:裁决来自系统里本就是唯一有效排序信号的对抗 critic 通道,由机械解析读出;"自评"禁令针对的是生成器给自己打分,不是对抗裁决。

## 5. 机械挡板与诚实台账(全部零模型判断)

- **G1 去重(只对加宽)**:新候选与池内任一候选的内容词 3-gram Jaccard > 0.8 → 丢弃,记浪费 2 调用。可选叠加一个冻结的确定性嵌入编码器做语义近重(它不是生成式自评,不可被提示词操纵)。深化子代**不做**去重(它本该与父高度重合),改做 **G1' 反向检查**:被反驳攻击的那个字段与父版本的编辑距离必须 > 0,否则视为空转,丢弃并标记父 deepen_exhausted。
- **G2 证伪条件棘轮(只对深化/锐化边)**:子代结构化字段里可证伪条件条目数 ≥ 父代(SHARPEN 于 0.45 时额外要求 ≥1)。违反 → 子代整条拒收,父标记 deepen_exhausted。注意:这是**不倒退阀**,不是"越多越好"的奖励——多塞条目不加任何分(排序只看裁决)。
- **G3 旧反驳字段**:深化子代的裁决 prompt 附上父代的最强反驳,critic 必须输出结构化字段 `旧反驳: 已解决 | 仍成立 | 不再适用`(机械解析)。`仍成立` → 子代分数强制封顶为父分 − ε(修了个寂寞);`不再适用` → 封顶为父分(主张挪走了,疑似说软,记 softening-suspect 标记入台账)。只有 `已解决` 才允许子代凭裁决分超越父代。
- **G4 血统上限**:每候选最多被深化 1 次;链深度上限见第 1 节表(B≤5 为 1,B≥6 为 2)。这同时是对同源盲区的结构性资金上限(见问题 4)。
- **G5 一次重裁上限**:未解析裁决先走正则兜底解析,仍失败才允许 1 次 REJUDGE,再失败按 0.45 行为处理。
- **台账**:每步记录 {动作, 目标候选, 调用数, 裁决原文+解析结果, 各门判定, 丢弃原因, 剩余预算, 停止原因码}。产物附打印摘要:宽/深各几步、浪费调用数、冠军血统(种子/深化几代)、冠军是否经异源复核。

## 6. ④ 失败模式(直面,不粉饰)

- **F1 说软保命漂移**(=简报问题 3):精修最省力的路是把主张说空。第一道防线是裁决刻度自身——"空泛到不可检验 = 致命 0.00",软化梯度指向 0 分而非高分;第二道是 G2 棘轮(不许删证伪条件)+ G3(`不再适用`不涨分)。残余风险:在字段间隙里加对冲措辞。对此只设**警报不设门**:对冲词表增量 + 深化链上的证伪条件密度趋势记入台账,超阈值亮灯给人看——因为词表是粗糙代理,按铁律不配当硬门。
- **F2 同源盲区放大**(=问题 4):详见第 7 节。结构上由 G4 封顶单血统吸金(≤5 调用/血统),运行时由 CROSS_EXAM 在 B≥6 时用 1 次异源复核准冠军,终分取两次裁决的最小值。
- **F3 裁决解析级联失败**:G5 兜底,0.50→按 0.45 行处理,不会卡死循环。
- **F4 全致命塌方**:所有种子和加宽都致命时,finish() 必须输出"本轮无站住候选",分 < 0.35 的条目强制带「未站住」标签——宁可交白卷,不许把最不烂的包装成产物。
- **F5 种子顺序偏置**:JUDGE_SEED 按初稿顺序,有偏但确定、可审计。B≥4 时引导后至少再裁 1 条种子以降方差(决策表的 JUDGE_SEED 分支天然会做到)。
- **F6 深化乒乓**:修好反驳 A 冒出反驳 B,再修 B 又丢 A——由链深上限 + G3 的旧反驳追踪封死,最多损失一条链的 2–4 调用。
- **F7 SHARPEN 被塞平凡证伪条件**:生成器加"若太阳照常升起则可证伪"式废条目。机械计数门挡不住平凡性——但计数门只是**前置条件**,分数仍由 critic 的第二次裁决给出:平凡条件不会让 critic 从 0.45 升 0.68。计数门防删除,critic 防注水,各管一段。
- **F8 循环真的不如 best-of-N**:如果深化夺冠率复测仍趋零(树的数据是 24 次 0 夺冠,虽然那是无靶点乱修,本循环是"最优者+点名反驳+棘轮门"的定向修,但必须重测不许赖账)——那么按第 8 节杀死开关,深化/锐化一键禁用,系统退化为"种子感知 best-of-N + 裁决停止 + 台账",不损失其余收益。

## 7. 简报"具体问题 1–5"逐条直答

**1. 循环站得住吗?"证据不足"怎么处理?**
站得住,但只在"决策表化"之后站得住;简报种子伪代码里的"连续两轮无更优"那部分站不住(见问题 2)。"证据不足+可证伪"的处理必须直面一个事实:**没有任何额外 LLM 调用能凭空造出证据**,所以"再攻一次"和"再多样化一次"都买不来置信度。机械上唯一有意义的升级是**扩大它的受攻击面**:SHARPEN 把证伪条件写得更具体、更可检验,然后让 critic 再攻一次。两个出口都算赢:(a) critic 有抓手了(升/降为轻微/严重/致命)→ 循环照常处理,说明"新颖"里藏着可攻的弱点;(b) 仍然攻不动 → 它以"更锋利的证伪条件 + 两次独立裁决存活"的状态被接受,**S2 停止,单列探索性前沿轨道**。接受即停是对的,但要停得有仪式:第二次裁决 + 分轨输出 + 台账注明,而不是混进"站住候选"里冒充。

**2. 收敛判据?"连续两轮无更优"够吗?**
不够,而且在这个预算下是**反面教材**:B=3 时数学上不可触发,B=8 时确认一次停滞烧掉一半预算。收敛判据必须是**单事件、裁决触发**:S1(无法反驳即停)、S2(前沿二次存活即停)、S4(无路可走即停)。这些都来自对抗 critic 的机械解析,不含模型自评。小预算下"几乎从不触发、退化为固定跑满"的指控对耐心计数成立,对单事件触发不成立——S1 在第 1 次调用就可能触发并当场省下全部剩余预算(只留半价的 K 位填充)。

**3. 精修会不会把候选越修越空?**
会,如果不设防——这是精修循环最真实的失败梯度。防线三层,全机械:(i) 裁决刻度里"空泛=致命 0.00"让极限软化直接归零;(ii) G2 棘轮:深化不许减少可证伪条件,注意它是不倒退阀而非奖励,多塞不加分,所以不违铁律;(iii) G3:旧反驳"不再适用"(=主张挪走)不涨分,只有"已解决"才许超父。残余的措辞级对冲用词表警报监控但**不设硬门**(粗糙代理不配当门)。此外结构性事实:软化收益的上限是 0.85,而 0.85 要求 critic 带证据攻过且攻不动——纯空话拿不到这个裁决。

**4. 同源 critic 的共同盲区会被循环放大吗?**
会,必须承认:一条在共享先验里系统性成立但实际错误的候选,拿到"无法反驳"后,S1 会让它当冠军,循环确实比 best-of-N 更快把资源和信任集中到它身上。**预算内无法根治**(根治=独立证据源或异构模型,超出 3–8 次调用的世界)。可行缓解:(a) **结构性封顶**:G4 让任何单血统最多吸 5 次调用,盲区候选无法吞掉全预算;(b) **异源复核**:B≥6 预留 1 调用,用不同模型(至少不同对抗人设+温度+要求列出"尝试过的攻击"清单)复核准冠军,终分取 min——1 次调用买在边际信息最大的点上;(c) **机械降级规则**:critic 给"无法反驳"时必须附结构化的"已尝试攻击"非空清单,清单为空则机械降级为"证据不足"——攻不动和没攻过不许同分;(d) **诚实标注**:产物中冠军带元数据"本裁决来自同源 critic",把剩余不确定性交给读者而不是藏起来。离线上,验证协议(第 8 节 Tier B)用冻结异源评审暴露盲区率。

**5. 拿什么客观、不可刷、不依赖模型评判的指标证明优于朴素 best-of-N?**
先把赌注说白:对照组取**最强基线**——"种子感知 best-of-N":全预算 B 都花在裁决免费种子上,B 条已裁决候选取 top-K(比简报说的"生成 N 条+各裁决一次"更强,因为它不花生成费)。循环每做一次 2 调用的定向动作,就是放弃 2 条种子的裁决抽签。指标分两层:

**Tier A(纯机械,零模型评判):**
- **M-A1 决策信息量(反事实重放)**:把台账里的裁决序列打乱重放,统计动作序列的改变率。树(Thompson,每臂 0–2 观测)≈ 不变(信号不驱动决策的实锤,即简报"树对照实测"待填项的机械化);本循环 = 决策表的确定性函数,改变率高。证明"信号真的在开车",不涉及任何质量评判,不可刷(它是控制器的离线性质)。
- **M-A2 合法深化夺冠率**(核心可否证指标):同题同种子、同预算 B,配对跑循环 vs 基线,n≥16 题。统计"深化/锐化产物合法夺冠"(合法 = 通过 G2/G3 门)的比率。**预注册阈值:B≥5 时 ≥25%。** 这是树用 0/24 被处死的同一把尺子,循环敢站上去:定向修最优者+点名反驳,对比树的抛硬币乱修,如果还是零,深化就该死(见 F8)。它由台账血统+冻结规则计算,运行时循环并不知道也无法优化"这个统计",不可刷。
- **M-A3 预算-层级 Pareto**:x=实际消耗调用,y=冠军裁决层级(类别序,机械)。循环的 S1/S2 早停应产生支配点:同层级更少调用,或同调用更高层级。种子数 S 小于 B 时(初稿常只给 3–5 条),基线饱和后必须以 2 倍价生成新候选——退化成循环的 WIDEN,循环严格不劣。
- **M-A4 浪费率**:去重丢弃与解析失败烧掉的调用占比,两臂对比,台账直出。
- **M-A5 交叉互攻存活计数**:两臂冠军接受同一组冻结攻击 prompt(同证据、k 个种子)的对称攻击,数"存活的独立攻击次数"。事件由模型产生,但**指标是预注册协议下 pass/fail 事件的机械计数**,两臂对称,管线无法给自己多刷存活次数(次数由 harness 控制),软化路线被 G2/棘轮+空泛致命封堵。

**Tier B(涉及模型但非自评、冻结、盲测、非运行时优化目标):**
- **M-B1 异源冻结评审**:与运行时 critic 不同的模型 + 冻结 prompt(哈希预注册),对两臂决赛候选做盲测配对(去溯源、随机顺序、等预算)。它不违"自评"禁令(既非生成器也非运行时 critic),不可刷(循环运行时从未见过它,不构成优化目标)。若甲方坚持零模型,则只用 Tier A 定夺——Tier A 本身有牙:M-A2 完全可能判循环死刑。

**预注册决策规则(杀死开关)**:保留深化/锐化,当且仅当 M-A2 ≥ 25% 且 M-B1 决胜对胜率 ≥ 60%;否则配置开关关闭 DEEPEN/SHARPEN,系统退化为"种子感知 best-of-N + 裁决触发停止 + 异源复核 + 台账"。注意退化态仍保有循环带来的三项免费收益(半价种子裁决、S1 早停省钱、诚实台账),所以这场实验没有输家——它只裁决"2 调用的定向动作"是否值回票价。

## 8. 铁律检验:逐判据自检

铁律:**一个不做真活也能满足的代理指标,一定会被不做真活地满足;绝不在粗糙代理上设硬门。** 逐条过:

| 判据/门 | 能靠"把话说空"满足? | 能靠"多生成几条"满足? | 判定 |
|---|---|---|---|
| S1 停止(无法反驳) | 否:空泛按刻度 = 致命 0.00,软化梯度背向 0.85;0.85 需 critic 带证据攻过。残余:critic 宽松漂移——设**警报**(跨轮"无法反驳"率 × 证伪密度联动监控),不设门 | 否:多生成不改变 best 的裁决 | 过 |
| S2 停止(前沿) | 否:需两次独立裁决存活 + SHARPEN 后证伪条件≥1(且第二次分数由 critic 给,平凡条件不升档,见 F7) | 否 | 过 |
| 深化触发(轻微/严重) | 不适用(触发来自 critic 对缺陷的分级,不是候选自述) | 否 | 过 |
| 加宽触发(致命) | 否 | 否:新候选各自过 critic,数量不给排名加分 | 过 |
| G1 去重 | — | 改写措辞可骗过 n-gram(伪多样性),但骗过后**不获得任何排名收益**,只浪费自己 2 调用,且浪费被 M-A4 计入 | 过(残余无利可图) |
| G2 棘轮 | 保留条目原文+软化周边可通过——但候选仍锁定原可证伪承诺,critic 仍可攻这些承诺;且棘轮是不倒退阀,**塞条目不加分**,无凑数激励 | 否 | 过(残余有界) |
| G3 旧反驳字段 | "不再适用"=挪走主张,已封顶不涨分 | 否 | 过 |
| 平分 tie-break | 只按创建时间,**明确禁用证伪条件计数当 tie-break**(那会重演"量化论断计数"惨案) | 否 | 过 |
| M-A2 指标 | 软化夺冠被 G2/G3 判"不合法",不计入 | 多生成不产生"深化血统" | 过 |
| 对冲词表 / 证伪密度趋势 | 可被改写绕过——**因此只做警报,永不做门**,严格遵守铁律 | — | 过(降级为警报) |

结论:本设计中没有任何一处把"数量型计数"用作奖励或硬门;计数只以"不倒退阀"和"分母"两种身份出现;所有排序权重都收敛到唯一经过实测有判别力的信号(对抗裁决)上,而对该信号自身的腐化(宽松漂移、同源盲区)设了警报、封顶与异源复核三重监控。

## 9. 一句话交付边界

砍掉:Thompson 选点、O(n²) 反传、Beta 双臂、采样轨迹。保留并升格:裁决解析(唯一有效信号,升格为控制器输入)、针对最强反驳的一遍精修(升格为决策表中的 DEEPEN/SHARPEN)、诚实台账(升格为验证指标的数据源)。新增:确定性决策表、单事件停止、五道机械门、异源复核、预注册杀死开关。全部在 3–8 次调用内闭合,调用数逐步入账、可核对。
