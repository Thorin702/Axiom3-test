# 设计方案:强化版 best-of-N + 条件性单次定向精修(BoN+G)

> 立场声明:本文从 **best-of-N 拥护派** 视角出发。核心判断:在 3–8 次额外 LLM 调用的硬预算下,任何"迭代循环"都必须先证明自己配得上顺序依赖带来的墙钟成本与 Goodhart 风险,而现有实测数据(24 次扩展中"加深"夺冠 0 次;8 题中 7 题冠军是初稿种子)强烈指向相反结论:**这个问题的方差在"第一稿生成"处,不在"精修"处**。把一次调用花在"再抽一张多样化的新牌"上,期望收益高于花在"打磨手里这张牌"上。下面给出可执行方案,并预注册"循环必须证明什么才配存在"的判据。

---

## 0. 证据回顾:为什么默认答案是 best-of-N

1. **加深从未赢过**:24 次扩展,"加深"候选合法夺冠 0 次。这不是小样本噪音——如果精修有正期望,0/24 的概率极低。
2. **冠军几乎总是初稿**:8 题里 7 题冠军是种子。说明生成分布的头部质量已经够到天花板,后续操作主要在消耗预算。
3. **现有树的"自适应"是装饰**:预算=3 时每臂 0–2 个观测,Thompson 采样≈抛硬币;排序阶段根本不读后验。所以被否掉的其实不是"智能的深化",而是"随机的深化"——这是循环派唯一合法的辩护点(裁决驱动≠抛硬币),我在第 6 节给它一次预注册的翻案机会,但仅一次。
4. **结构性优势——并行**:best-of-N 的生成波与裁决波各自可并行,墙钟≈2 个调用时长(1–3 分钟);任何循环天然串行,4 次扩展≈8 次串行调用(4–12 分钟)。墙钟是机械指标,刷不了。
5. **结构性优势——不放大 Goodhart**:best-of-N 对 critic 只施加"N 选 1"的选择压力(≈log₂N 比特);迭代精修是**朝着 critic 的判分梯度定向爬坡**,每一轮都在把候选往"这个 critic 攻不动"的方向优化。critic 与生成器同源时,后者是在系统性放大共同盲区(详见问题 4)。

---

## 1. 方案总览

**BoN+G = 预算规划(确定性) → 阶段 A:并行铺宽 → 阶段 B:至多一次、有挡板的定向精修 → 排序输出 + 诚实台账。**

保留简报指定要保留的三样东西:critic 裁决解析(唯一净增信号)、"针对最强反驳的一遍精修"(降级为条件性附件,而非架构主体)、诚实台账。砍掉:Thompson、反传、Beta 臂、轨迹记录、以及**任何形式的多轮循环**。

### 1.1 预算会计(先算清,不边跑边定)

- 记 `B ∈ [3,8]` 为额外调用预算;1 次生成 = 1 次调用,1 次裁决 = 1 次调用。
- 记 `s` = 尚未裁决的种子数(种子生成本身不占 B,但欠的裁决账必须还——没分的候选无法参与排序)。
- 精修预留 `r = 2 if B − s ≥ 4 else 0`。
- 新增宽候选数 `K = floor((B − s − r) / 2)`。
- 余数 ≥1 且池中存在"证据不足"候选时,余下 1 次调用可用于"第二考官取最小值"复核(见问题 1)。

| B | s | r | K | 解读 |
|---|---|---|---|------|
| 3 | 2 | 0 | 0 | 只够还裁决账,啥花活都不配上——**循环在此预算下更是空谈** |
| 5 | 2 | 0 | 1 | 1 条新宽候选 |
| 8 | 2 | 2 | 2 | 2 条新宽候选 + 1 次条件精修 |

### 1.2 控制流(①,伪代码)

```
输入: seeds[](初稿候选, 冻结、不占预算), B, 证据集 E, 角度槽位表 ANGLES(预置)

# ---- 预算规划(确定性) ----
s = |未裁决 seeds|
r = 2 if B - s >= 4 else 0
K = floor((B - s - r) / 2)
slots = 从 ANGLES 中选 K 个与 seeds 词面重合度最低的槽位   # 机械分派: 3-gram Jaccard 最小化

# ---- 阶段 A: 并行铺宽 ----
并行:
    for seed in 未裁决 seeds: critic(seed) → 裁决入池          # s 次
    for slot in slots:        gen(slot)   → cand[slot]         # K 次
汇合后并行:
    for cand: critic(cand) → 裁决入池                          # K 次
去重: 池内两两 3-gram Jaccard > 0.35 ⇒ 留分高者, 弃者入台账(预算不退还)

champ = argmax(池, 存活分)
# 破平(全机械): 裁决等级 > 证伪条件字段非空 > 生成序(先到先得)

# ---- 阶段 B: 条件性单次定向精修(至多一次, 永不循环) ----
if r == 2 and champ.等级 ∈ {严重, 轻微} and champ.反驳文本非空:
    v  = refine(champ, 靶向其最强反驳)        # 1 次
    dv = critic(v)                            # 1 次; 单掷, 禁止重掷
    if 等级严格改善(champ → v) and 反空泛挡板(champ, v):
        v 入池(champ 保留, 不覆盖不删除)
    else:
        v 弃, 台账记录败因(等级未改善 / 挡板拦截)
elif r == 2:
    # 冠军已站住(0.85)、或证据不足、或全池致命 ⇒ 精修无靶点/无必要
    cand = gen(下一个未用槽位); critic(cand); 入池             # 预留改投一条宽候选

# ---- 输出 ----
top-K 按存活分排序; "证据不足"者带【探索前沿】标签原样输出
台账: 每次调用的类型/槽位/裁决/弃用原因/预算流水/挡板判定/critic prompt 版本哈希/单掷审计位
```

### 1.3 停止条件(②)

**确定性预算耗尽,没有收敛启发式。** 三个提前省钱点,全部由机械信号触发:

1. 阶段 A 后冠军等级 = `无法反驳(0.85)` ⇒ 精修预留改投宽候选(或在 B 紧张时直接结束)——已站住的候选没有可修靶点,继续打磨只有 Goodhart 风险没有信息增益。
2. 阶段 B 触发条件不满足(冠军是致命/证据不足/无反驳文本)⇒ 预留改投宽候选。
3. 预算规划本身就是停止条件:每一步花在哪、花几次,运行前已定死。**没有"收敛判断",就没有可被刷的收敛判断。**

### 1.4 "往宽/往深"由什么信号驱动(③)

- **宽是默认,深是例外。** 宽的数量 K 由预算算术预先确定,不由任何运行时判断驱动——这是对 0/24 与 7/8 数据的直接兑现。
- **深的唯一触发器**:冠军裁决等级 ∈ {严重 0.35, 轻微 0.70} 且反驳文本非空。即:**由对抗 critic 的机械解析结果驱动,不是模型自评,不是候选自己举手**。这两个等级的语义恰好是"critic 指出了具体可修缺陷"——精修有靶点才开火。
- `致命` ⇒ 宽(该方向已死,换角度);`无法反驳` ⇒ 不动(没靶点);`证据不足` ⇒ 永不深化(见问题 1);`裁决未解析` ⇒ 本地重解析一次(零调用),仍失败则 0.50 记账并打旗,**禁止重掷 critic**。

### 1.5 机械挡板(全部不依赖模型判断)

**挡板一律是单向否决(veto),不是加分项。** 这是对铁律的结构性回应:否决型判据"多做坏事会被拦",加分型判据"多做样子能得分"——只有后者会被廉价刷掉。

1. **反空泛挡板**(精修接受的第二把钥匙):
   - 机械提取 champ 的具体元素集合 S:数字+单位、命名实体、日期、证据引用 ID(正则即可)。
   - 精修版 v 的集合 S′ 须满足 `|S \ S′| / |S| ≤ 0.2`,或每个被删元素在同字段有同类型替换物。
   - v 的证伪条件字段非空,且字符数 ≥ champ 的 0.8 倍(只设下限作否决,**不设上限、不加分**——填充凑长度只能骗过这道下限,骗不过第一把钥匙)。
   - 单向性:S′ 变大不加分。把话说空 = 删具体元素 ⇒ 被拦;堆砌数字 ⇒ 无利可图。
2. **等级严格改善**(精修接受的第一把钥匙):在格 `致命 < 严重 < 轻微 < 无法反驳` 上必须严格上移;`证据不足` 不在此格上,不可比,也因此永远不是精修对象。分数抖动(0.68→0.70)不算改善。
3. **单掷裁决铁则**:每条候选一生只被主 critic 裁决一次。若因任何原因产生多次裁决,记账取**最小值**,永不取最大值。这封死了"重掷刷出无法反驳"的通道。
4. **去重否决**:3-gram Jaccard > 0.35 弃置且不退预算——伪多样性只会浪费自己的调用,刷不出有效 N。
5. **精修不覆盖父本**:champ 与 v 并存参与排序。精修最坏情况 = 浪费 2 次调用,永远不会毁掉已有冠军。

### 1.6 失败模式(④,诚实列举,含我方案自己的)

| 失败模式 | 谁中招 | 缓解 | 残余风险 |
|---|---|---|---|
| 天生软:候选生来就"软而不空",拿 0.85 | BoN 与循环**同等中招**(选择偏置) | 分级表已定价(空泛到不可检验=致命 0.00;无证伪条件的新颖=0.45);证伪条件为必填结构字段 | 中等,只有 M5 时效存活能最终揭穿 |
| 越修越软 | 循环重灾区;BoN+G 仅阶段 B 暴露 | 两把钥匙 + 单轮上限(软化是复利过程,一轮封顶即有界)| 对冲话术(加"可能/在某些条件下"而不删具体元素)可能骗过挡板——记台账旗,不设硬门(铁律) |
| 同源盲区放大 | 循环重灾区;BoN 只受选择压力 | 见问题 4 | 同预算内不可根除,只能不放大 |
| 伪多样性(K 条近似重复) | BoN 特有 | 角度槽位强制分派 + 去重否决 + N_eff 指标 | 槽位表本身质量依赖人工维护 |
| 槽位约束压制自由采样的峰值 | BoN+G 特有 | 预注册消融 A1(槽位 vs 自由采样)裁决,输了就删槽位 | 低 |
| 全池致命且预算尽 | 两者都会 | 照实输出最高分 + 致命标签 + 台账写明,**不装** | 无 |
| 裁决解析失败堆积 0.50 | 两者都会 | 本地重解析;失败打旗;禁止重掷 | 0.50 候选混入中段排名,台账可见 |
| critic 单次裁决的方差 | 两者都会,循环更敏感(每步决策都吃这口噪音) | BoN 只在排序处消费一次;有闲钱时对"证据不足"做第二考官取最小 | 中等 |

## 2. 逐条回答简报问题

### 问题 1:循环站得住吗?"证据不足"怎么办?

**循环在此预算下站不住。** 三处硬伤:(a) 它的主体动作"深化"实测 0/24,而它每轮串行消耗 2 次调用去做这件事;(b) 它的收敛判据在 B=3 时是装饰(见问题 2 的算术);(c) 它唯一的真贡献——"针对最强反驳的一遍精修"——用 2 次调用的条件性附件就能完整保留,不需要循环这个壳。

**"证据不足"(0.68)的处理:接受即停,永不深化,标签输出。** 理由是机械的,不是态度的:

- 精修需要靶点。"证据不足"的定义恰是"critic 没有现成证据可攻"——没有反驳文本,精修就是盲改,而盲改正是 0/24 里那种深化。
- "再攻一次"在单掷铁则下被禁止:对同一候选重掷 critic 是在同一分布里重采样,取好结果 = 刷分,取坏结果 = 白花钱,取平均 = 花一次调用买噪音削减,不如买一条新候选。
- **机械提高信心的唯一正路:多考官取最小值。** 若预算余数 ≥1,对"证据不足"候选用一个不同攻击视角的 critic prompt(版本哈希入台账)再裁决一次,**合并取 min**。取 min 只可能降分不可能升分,故不可刷;能扛住两个视角仍保 0.68 的候选,前沿标签更硬气。
- 辅助机械信号(只做标签/破平,不做门,遵守铁律):证伪条件字段引用的证据锚点 ID 是否真实存在于证据集 E(字符串匹配可验)。

它是产品最想要的产出,所以给它**保送 top-K 的资格 + 显式前沿标签**,让下游用它的"具体可证伪条件"去做真实世界验证——这才是对新颖候选唯一诚实的信心来源,LLM 内部再多轮互搏都替代不了。

### 问题 2:收敛判据

**"连续两轮无更优"在小预算下是纯装饰,算术如下。** 一次扩展 = 2 次调用。B=3~5 ⇒ 最多 1–2 次扩展,判据需要"确立 best 后再看两轮",触发时刻必然与预算耗尽重合——它从未省下任何调用,却引入了一个看起来在思考的假开关。B=8 ⇒ 4 次扩展,判据最早在第 3 次扩展后触发,至多省 1 次扩展,且省下的恰是循环里期望收益最高的"再抽一张"。

**我的替代:根本不要收敛判据。** 预算规划在运行前确定每次调用的用途,停止 = 计划执行完毕。仅有的两个"提前改道"开关(冠军 0.85、精修无靶点)都是裁决等级的机械读数,不涉及"有没有更优"这种需要趋势判断的量。**不存在的判据不会退化,也不会被刷。**

### 问题 3:精修的反效果(越修越空)

**会,而且是系统性的,机制上无法靠"提醒模型别软"解决**:存活分 = 抗攻击度,缩小可攻面的最省力方向就是软化;精修是在这个分数上做定向优化,梯度天然指向软。分级表只斩了极端(空泛到不可检验=致命),"软而不空"的中间地带畅通无阻。**这正是我把精修从"循环主体"降级为"单次附件"的首要原因——软化是逐轮复利的,轮数=1 是最强的机械挡板。**

四道机械挡板(见 1.5):两把钥匙(等级严格上移 + 具体元素非回归 diff)、单轮封顶、父本保留。注意反空泛挡板的设计要点:它是**非回归约束**(不许删),不是**丰度奖励**(不奖多)。曾经失败的"量化论断计数"是丰度奖励,奖励凑数;非回归 diff 无数可凑——你只能因删除具体内容被拦,不能因堆砌数字得分。

残余风险照实说:不删元素、只加对冲副词的"包边式软化"能同时骗过两把钥匙(critic 可能把包边后的候选从严重升到轻微)。对此我拒绝加"对冲词密度门"——那是又一个粗糙代理,必被廉价满足(换同义词绕开词表)。处理:台账记对冲词密度变化作**旗标**供人审,硬裁决交给 M5 时效存活。

### 问题 4:同源盲区

**循环放大它,best-of-N 不放大它——这是两种架构的本质差异,不是程度差异。** 定量地说:N 选 1 的选择对 critic 偏好只泄露 ≈log₂N ≤ 3 比特优化压力,且候选在见到任何裁决之前已生成完毕,**没有任何候选是"为了讨好这个 critic 而写"的**。循环则相反:每一轮精修都读取 critic 的反驳文本并针对性改写,k 轮就是 k 步朝同源先验的梯度下降;一条"在该模型先验里成立但实际错误"的候选,会被循环判为无法反驳并停机庆祝,还在台账里记成"收敛"。

缓解(诚实版):同预算、同模型下**不可根除**,只能选择不放大的架构 + 两个便宜的去相关手段:(a) 主 critic 之外预置 1–2 个攻击视角互异的 critic prompt 变体,用于第二考官取 min 与终审(仍是同一模型,只能去掉 prompt 层面的相关性,去不掉权重层面的);(b) 验证指标里的 held-out critic(运行期间不可见,见 M1)与时效存活(M5)。**任何声称在 8 次调用内"解决"同源盲区的设计都在撒谎。**

### 问题 5:什么客观指标能证明循环优于朴素 best-of-N?(诚实判断)

**诚实判断:以现有证据,证明不了,而且举证责任在循环一方。** 0/24 与 7/8 不是"循环调参没调好"的证据,是"这个问题的收益曲面在宽不在深"的证据。我唯一承认的翻案理由:实测的 0/24 发生在"近似抛硬币选深化"之下,而裁决驱动的深化是不同的策略——所以循环配得到**一次**预注册实验,输了就永久出局。判据见第 4 节与第 6 节。

同时按同一标准要求我自己:BoN+G 相对朴素 BoN 的两个增件(角度槽位、阶段 B)也各自预注册消融,任何增件证明不了自己就删掉,退到更朴素的版本。**标准对双方同刻度,这才叫不和稀泥。**

## 3. 验证指标(⑤:客观、不依赖模型自评、不可刷)

所有实验:同题同种子,种子冻结且两臂共享(封死"故意用弱种子抬高精修胜率"的通道);两臂总调用数严格相等;台账全量留存。

- **M1 配对冠军终审(主指标)**:每臂的最终冠军交给一个 **held-out critic**(固定 prompt、版本哈希预注册、两臂运行期间均不可见不可用)各裁决一次,比较等级/分数。这不是模型自评——是对抗性考官;不可刷——运行期看不见它,无从对它优化。局限照实写:考官仍同源,M1 度量的是"换个没被刷过的考官还站得住吗",不是真值。
- **M2 深化产出率(循环/阶段 B 的存在性指标)**:台账统计,最终冠军是精修产物、且等级严格改善于父本、且通过反空泛挡板的运行占比。纯台账推导,机械可查;想刷它必须真的产出更能扛打且没软化的改写——那就是做真活。
- **M3 有效多样性 N_eff**:去重后存活候选数 / 生成候选数。机械;近似重复刷不上去(被去重吃掉),只会浪费自己的预算。
- **M4 双账本**:LLM 调用数 + 墙钟时间,分臂如实记录。物理量,不可刷。循环必须公开自己的串行延迟倍数。
- **M5 时效存活(唯一的地面真值,慢)**:冠军的"具体可证伪条件"交由下游/人工在后续核查,统计存活率。凡产品声称要"可验证、有新意",就必须建这条慢反馈,否则所有快指标都悬空。
- **M6 单掷审计位**:台账布尔项——冠军得分从未受益于任何形式的裁决重掷。审计项,非优化目标。

**判决规则(预注册,先写死再跑)**:16 个配对题目,等调用预算。
循环若要存在,须**同时**满足:
1. M1 上对等预算 BoN+G 单边 Wilcoxon 符号秩检验 α=0.05 胜出;
2. M2 ≥ 25%(它的招牌动作得真能赢,而不是 0/24 的延续);
3. 墙钟 ≤ BoN+G 的 2 倍。
任一不满足 ⇒ 弃循环,上 BoN+G。
消融同规:A1(槽位 vs 自由采样,比 M1/M3)、A2(阶段 B 开/关,比 M1/M2)——A2 若 M2 = 0,删阶段 B,上纯 best-of-N。

---

## 4. "循环必须证明什么才配存在"——预注册清单

1. **深化必须赢**:M2 ≥ 25%,且每个计入的深化冠军都通过反空泛挡板。0/24 的历史成绩下,拿不出这个就没有任何谈判余地。
2. **赢在等预算**:对比臂是本方案 BoN+G(不是被削弱的稻草人),总调用数逐题相等。
3. **赢给没被刷过的考官看**:M1 用 held-out critic,不用运行内 critic 的分数自证(运行内分数是循环的直接优化目标,用它自证 = 用训练集报成绩)。
4. **付得起串行税**:墙钟 ≤ 2×,并在台账公开。
5. **一次机会**:预注册、跑完、按判决规则执行。不许"再调调参数重跑"——那是在指标上做梯度下降,恰是铁律要禁的事。

---

## 5. 铁律检验(逐条过)

> 一个不做真活也能满足的代理指标,一定会被不做真活地满足;绝不在粗糙代理上设硬门。

- **深化触发器(裁决等级∈{严重,轻微})**:等级由对抗 critic 产出,候选无法自报;"把话说空"拿到的是致命(0.00)或无证伪条件的 0.45,不是精修资格。不可廉价满足。
- **精修接受(两把钥匙)**:钥匙一(等级严格上移)可被软化 Goodhart ⇒ 被钥匙二(非回归 diff 否决)对冲;钥匙二可被"只加不删"绕过 ⇒ 但绕过者仍须过钥匙一,且单轮封顶限死了复利。残余的"包边式软化"记旗不设门——**拒绝为了堵一个代理漏洞再造一个更糙的代理硬门**(对冲词密度门被明确否决,理由见问题 3)。
- **宽候选数 K**:预算算术定死,多生成几条既无门可过也无分可加;近似重复被去重否决且不退预算。"多生成几条"这条廉价通道不存在。
- **停止条件**:确定性计划,无收敛启发式,无可刷面。
- **验证指标**:M1 held-out(运行期不可见)、M2 台账推导+挡板过滤、M3/M4 物理量、M5 地面真值、M6 审计位。唯一次级风险:M2 的 25% 阈值可能诱使未来有人放松挡板来凑数——故预注册条款写明:**挡板定义与阈值同版本冻结,改挡板 = 重新预注册重跑,旧成绩作废。**
- **总原则兑现**:全文所有机械判据均为**单向否决或事后审计**,无一处"做了某个动作就加分"的丰度奖励——铁律击中的正是丰度奖励(量化论断计数),本方案在结构上不含这一类。

## 6. 结语(直说)

树的问题不是"树",是"假装自适应"。循环的问题也不会因为"真自适应"就自动解决——它还得回答:在一共只有 1–4 次扩展的世界里,串行地雕琢一个 0/24 胜率的动作,凭什么好过并行地多抽两张牌?我的答案写在判决规则里:凭 M1+M2+墙钟,一次预注册,赢了我认,输了就请把循环和那棵树葬在一起,产线上 BoN+G,B=3 时它自动退化为"还清裁决账的诚实排序",B=8 时它是"3–4 条强制多样候选 + 一次有挡板的靶向精修"。简单、并行、每个判据可审计,且没有任何一个部件在假装思考。
