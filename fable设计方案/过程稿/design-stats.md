# 裁决闭环设计:预算统计派审查报告

> 立场:一切以调用会计为准。每条新候选 = 生成 1 次 + 裁决 1 次 = **2 次调用**,这是本系统的原子成本单位。任何"自适应""收敛""闭环"的说法,先过账,再谈价值。

**核心主张(TL;DR)**:在 3–8 次调用的预算下,简报里那个循环在算术上**塌缩为"best-of-N + 至多 1–2 次条件精修"**。"连续两轮无更优"在预算 3 时触发概率恒等于 0(结构性不可能),应删除,换成三条零成本/低成本停止规则。精修的全部期望增益只有一条路:0.70(轻微)→ 0.85(无法反驳),每次 2 调用换 p×0.15 的期望分数增益,而现有实测(深化夺冠 0/24)给出的 p 点估计为 0。因此:**默认部署 best-of-N,条件精修作为一个待验证的"廉价期权"挂在末端,用预注册的配对实验决定其生死;证明不了就删。**

---

## 0. 会计规则(先定账本,再谈设计)

预算 B 严格计所有 LLM 调用:生成 = 1,裁决 = 1,重裁决 = 1。两种制度:

- **制度甲(c_s=1)**:初稿种子由上游流水线产出,生成成本沉没,种子只付裁决费 1 调用/条。
- **制度乙(c_s=2)**:种子生成也计入预算,每条种子 2 调用。

简报"默认预算=3、每扩展一条候选裁决一次"的描述与"3–8 次调用"存在歧义(3 次扩展 = 6 次调用 > 3)。本设计**强制采用严格调用计数**;若上游实际按"扩展次数"计,所有表格乘 2 即可。以下默认制度甲,制度乙单列。

会计恒等式:`B ≥ N_s·c_s + 2L + R`,其中 N_s = 裁决的种子数,L = 循环步数(宽或深,每步 2 调用),R = 重裁决次数(每次 1 调用)。

### 完整调用会计表

**制度甲(种子生成沉没,c_s=1)**

| 预算 B | 可行拆分 (N_s, L, R) | 池内候选数 | 循环步上限 | 墙钟(30–90s/调用) | 推荐拆分 |
|---|---|---|---|---|---|
| 3 | (3,0,0) / (2,0,1) / (1,1,0) | 3 / 2 / 2 | **1** | 1.5–4.5 min | (3,0,0):纯 best-of-3 |
| 5 | (5,0,0) / (3,1,0) / (4,0,1) / (1,2,0) | 5 / 4 / 4 / 3 | 2 | 2.5–7.5 min | (3,1,0):3 种子 + 1 条件步 |
| 8 | (8,0,0) / (6,1,0) / (4,2,0) / (2,3,0) | 8 / 7 / 6 / 5 | 3 | 4–12 min | (4,2,0) 或 (6,1,0) |

**制度乙(种子也计费,c_s=2)**

| 预算 B | 可行拆分 (候选数, L) | 结论 |
|---|---|---|
| 3 | (1,0)+1 闲置 | **循环不存在**:1 条候选,谈不上池 |
| 5 | (2,0)+1 / (1,1)+1 | 至多 1 步 |
| 8 | (4,0) / (3,1) / (2,2) / (1,3) | 推荐 (3,1) |

### 支配性引理(制度甲下的硬结论)

只要还存在**未裁决的种子**,任何"宽步"(2 调用换 1 条新候选+分数)都被"裁决 2 条现有种子"(2 调用换 2 条候选的分数)**严格支配**。推论:**宽步只在种子池耗尽后才允许**。循环里唯一提供种子买不到的东西的动作是精修(0.70→0.85 转化)。这一条把循环的"自适应叙事"削成一句话:**先把便宜的分数买完,再考虑贵的**。

## ① 控制流(伪代码,逐行带成本注释)

```
常量:
  B                    # 总调用预算,严格计数
  REFINE_CAP = {B=3: 0, B=5: 1, B=8: 2}     # 精修次数硬上限
  分值 = {致命:0, 严重:.35, 无证伪:.45, 未解析:.50, 有证伪:.68, 轻微:.70, 无法反驳:.85}

状态: pool=[], ledger=[], spent=0, refines=0, dead_wides=0

## 阶段一:种子裁决(支配性:未裁决种子存在时,其余动作一律劣势)
while 有未裁决种子 and spent+1 <= B:
    s = 取下一条种子; 裁决(s); spent += 1
    if s.档 == 未解析 and spent+1 <= B:
        重裁决(s) 一次; spent += 1              # 最便宜的信息:1 调用,仅一次
    pool.加入(s, 去重)
    if pool.最优分 == 0.85: goto 收尾            # 天花板停:0 额外成本

## 阶段二:条件循环(种子已尽;宽/深同价 = 2 调用/步)
while spent+2 <= B:
    best = argmax(pool)
    switch best.档:
      case 无法反驳(0.85):
          break                                  # 天花板停:"更优"在此量表上不存在
      case 轻微(0.70) if refines < REFINE_CAP:
          r = 精修(best, 针对其最强反驳); spent += 1
          # 机械棘轮(0 调用):r 若丢失 parent 的任一{数字/命名实体/可证伪条件},
          # 弃 r,ledger 记"精修被棘轮拒收",refines += 1,continue
          裁决(r); spent += 1; refines += 1; pool.加入(r, 去重)
      case 轻微 if refines >= REFINE_CAP:
          break                                  # 精修徒劳停
      case 证据不足-0.68:
          if 未做过保险宽步: 宽步(); spent += 2   # 一次,买保险
          else: break                            # 0.68 是精修惰性档,调用换不来证据
      case 全池 <= 0.45:
          宽步(要求与池内候选角度不同); spent += 2
          if 连续 2 次宽步后全池仍致命: break      # 宽步徒劳停
    ledger.append(步骤, 动作, 档位, 花费, 理由)

## 收尾
排序 = 按存活分取 top-K
探索槽:若存在"首次裁决即 0.68 且自带可证伪条件"的候选,保留 K 中 1 席给其中最优者
       (条款是精修后补加的不算——防 0.45→0.68 刷分,见铁律检验)
ledger 记:停止原因 ∈ {天花板, 预算耗尽, 精修徒劳, 宽步徒劳},
          各档计数,每次精修的(前档→后档),p̂ 与 q̂85 累计值
```

## ② 停止条件(先杀掉"连续两轮无更优")

**命题:"连续两轮无更优"在 B=3 时触发概率 = 0,结构性不可能,与分数分布无关。**

证明:触发需要在"best 确立"之后完成 2 个完整循环轮,每轮 = 1 生成 + 1 裁决 = 2 调用,共 4 调用;还需至少 1 调用先裁决出一个 best。4 + 1 = 5 > 3。即使把种子裁决也算白送,4 > 3 仍成立。∎

各预算下该判据的经济价值:

| B | 触发可能性 | 触发时机 | 相对"预算耗尽即停"的节约 |
|---|---|---|---|
| 3 | 0(结构性) | — | 0 |
| 5 | 仅当两步全部无更优 | **与预算耗尽同时** | 0 |
| 8 | 可能 | 最早在第 5–6 调用后 | 至多 2 调用(25%),且以先烧掉 4 调用"确认轮"为代价 |

更糟的是它与封顶量表的病态交互:**一旦 best = 0.85,"更优"在数学上不可能**(0.85 是最高档),该判据退化为"固定再烧 4 调用,然后停"——一个在任何预算下都纯亏 4 调用的税。简报的怀疑(小预算下退化成固定跑满)不仅成立,而且比怀疑的更糟:它在 B≤5 下**恒等于**固定跑满。

**替代停止条件(全部零调用成本或负成本)**:

1. **天花板停**:池内出现 0.85 → 立即停。节约随运气可达全部剩余预算。
2. **预算停**:`spent + 2 > B` → 停(连一步都买不起)。
3. **精修徒劳停**:精修次数达 REFINE_CAP → 停。CAP 由 p̂ 台账全局校准(见 ④-3)。
4. **宽步徒劳停**:连续 2 次宽步后全池仍 ≤ 0.45 → 停,产物打"无存活候选"旗,如实交付最高分者。

## ③ "往宽/往深"由什么信号驱动

由**裁决档位 × 预算状态**的二维决策表驱动,不含任何模型自评、不含 Thompson 采样:

| 池内状态 | 剩余预算 | 动作 | 成本 | 会计理由 |
|---|---|---|---|---|
| 存在未裁决种子 | ≥1 | **裁决种子** | 1 | 支配性引理:半价买分数 |
| best = 0.85 | 任意 | **停** | 0 | 封顶,任何调用期望增益 = 0 |
| best = 0.70,refines < CAP | ≥2 | **深**(针对最强反驳精修) | 2 | 全系统唯一 +0.15 通道 |
| best = 0.68(证据不足) | ≥2 | **宽 ×1 后停** | 2 | 精修无法制造证据;买一次保险 |
| best = 0.50(未解析) | ≥1 | **重裁决同一候选 ×1** | 1 | 最便宜的信息,禁止为解析失败花 2 调用精修 |
| 全池 ≤ 0.45 | ≥2 | **宽**(限连续 2 次) | 2 | 修复致命候选 = 重写 = 宽的贵版 |

深与宽的临界判据(种子耗尽后,两者同价 2 调用):

- 深的每步期望增益 = **p × 0.15**(p = 0.70→0.85 转化率,仅此一档有头寸);
- 宽的每步期望增益 ≈ **q85 × (0.85 − best)**(q85 = 新鲜候选拿"无法反驳"的率);
- best=0.70 时:**深优于宽 ⇔ p > q85**。种子未耗尽时裁决种子半价,门槛翻倍:**p > 2·q85**。
- p 与 q85 都从 ledger 免费累计,不需要任何额外调用。现有证据:24 次扩展深化夺冠 0 次。按 Thompson≈抛硬币计约 12 次深化尝试,0/12 的 95% 置信上界(rule of three)≈ 0.25;即便 24 次全是深化,上界也只有 0.125。p 的点估计是 **0**。深这条腿目前是靠信仰站着的。

### 分数天花板结构与精修期望增益(逐档过账)

| best 档 | 精修的名义头寸 | 实际可得 | 每 2 调用期望增益 |
|---|---|---|---|
| 0.85 | 0(封顶) | 0 | **0 —— 精修 0.85 是纯烧钱,禁止** |
| 0.70 | +0.15 | critic 已指明具体小缺陷,可修 | **0.15p(全系统唯一有意义通道)** |
| 0.68 | +0.17 | 缺的是证据,精修只能改措辞 | ≈0(精修惰性档) |
| 0.50 | +0.35 | 是解析问题不是内容问题 | 重裁 1 调用即可,精修属浪费 |
| 0.35 / 0.00 | +0.35~0.85 | "修复重大缺陷"= 重写 = 宽 | ≤ 宽,且带锚定劣化风险 |

结论:整个"往深"分支的价值被压缩在一个点上——**0.70→0.85,+0.15,概率 p**。循环值不值得存在,等价于 p 是否显著大于 q85。这是一个可测的单参数问题,不是架构信仰问题。

## ④ 失败模式

1. **天花板锁死**:首条种子即 0.85 → 循环零步,产物 = best-of-1。这是节约不是故障,但 ledger 必须记"天花板停于第 x 调用",否则运营侧会误以为循环没跑。
2. **全池致命螺旋**:宽、宽、预算尽,无存活候选。挡板:宽步徒劳停 + 产物打旗如实交付。
3. **0.70 精修跑步机**:p≈0 时反复精修反复失败。挡板:REFINE_CAP(3/5/8 → 0/1/2)+ 全局杀开关:预注册"累计 30 次条件精修后,若 p̂ 的 Wilson 95% 上界 < q̂85,则配置层面禁用深分支"。
4. **越修越空**(详见问题 3):精修靠削弱主张换存活分。挡板:机械棘轮(0 调用)。
5. **同源盲区放大**(详见问题 4):挡板:禁止精修 0.85(本设计已含)+ 场外抽审。
6. **解析失败循环**:0.50 反复重裁。挡板:重裁上限 1 次,之后 0.50 为终态。
7. **去重误杀**:机械去重把共享模板句的真不同候选判为重复。挡板:去重只比较候选的主张字段而非全文;阈值在 ledger 上留样本供校准。

## ⑤ 客观、不依赖模型自评、不可刷的验证指标(含问题 5 的实验设计)

原则:**循环内 critic 分数是被优化的对象,永远不得作为评价终点**(Goodhart)。终点必须在循环外、异源、盲评、预注册。

### 两段式设计(先用免费的机械门,省下评审预算)

**第 0 段:机械门(零评审成本,ledger 自动产出)**

- **M0a 深化转化率**:p̂ = 0.70→0.85 成功次数 / 条件精修次数。预注册:累计 30 次后,若 Wilson 95% 上界 < q̂85(种子"无法反驳"率,同一 ledger 免费统计),**判死,直接 best-of-N,不进第 1 段**。0/30 的上界 ≈ 0.10——只要种子有一成概率直接拿 0.85,深分支就在期望上被支配。
- **M0b 冠军身份率**:循环冠军 ∉ 种子集的比例(纯字符串比对)。预注册:< 25% → 循环无边际产出,判死。(现有数据 8 题 7 题冠军是种子,即 12.5%,按此门当场不过。)

**第 1 段:配对对照实验(仅当第 0 段全过)**

- **臂**:A = 纯 best-of-N(预算 B 全部用于种子裁决);B = best-of-(N−1) + 末端保留 2 调用,仅当 best=0.70 时做一次条件精修,条件未触发则补裁 1 条种子(此时 B 与 A 完全一致)。两臂总调用严格相等 = B。
- **配对**:同题、同种子集(种子生成一次共用)、可固定处固定采样种子;每题产出一对冠军。
- **自动平局**:条件未触发的题两臂冠军逐字节相同,机械判平局,**不送评审,零成本**。
- **Held-out 评判**:不同模型家族、从未出现在任何循环内的独立裁决方;盲评(去除臂标签、随机左右序);同一固定 rubric,rubric 明文惩罚不可检验的空泛主张;每对 1 调用。
- **主终点**:非平局对中 B 臂胜率;符号检验,单侧 α = 0.05,H0: 胜率 ≤ 0.5。
- **预注册排除**:凡精修中通过补加证伪条款实现 0.45→0.68 的升级(ledger 有 clause-added 标),该对不计入 B 臂胜局。
- **样本量**(符号检验,80% 功效):

  | 目标胜率 | 需非平局对数 |
  |---|---|
  | 0.65 | 67 |
  | 0.70 | 37 |
  | 0.75 | 23 |

  总题数 = 非平局对数 / (触发率 π × (1 − 触发后平局率))。例:π = 0.4、触发后平局 0.2,检出 0.70 需约 **116 题**;两臂运行成本 116×2×8 ≈ 1856 调用 ≈ 15–46 机时(可并行)。这就是"证明"的价签,写在这里防止事后嫌贵偷工。
- **禁止 optional stopping**:样本量与检验预注册;如需期中分析,预注册一次 O'Brien–Fleming 界。
- **判定规则(预注册)**:胜率 ≥ 0.65 且 p < 0.05 → 采纳条件精修;**其余一切结果 → 默认决策 = best-of-N,删除循环分支**。举证责任在循环侧;现有 0/24 的先验也压在这一侧。
- **长线真值(资产,非门)**:带可证伪条件的冠军进入时间前瞻复核清单,到期机械核对。这是系统里唯一的真·地面真值,慢,但不可刷。

**不可刷性论证**:主终点是异源盲评的配对偏好 + 两道纯机械门;循环内分数不出现在任何终点;"多生成几条"只会推高 A 臂同等受益(配对同预算);"把话说空"过不了 held-out rubric 且被棘轮拦在上游;精修产出近重复以骗过 M0b,则 held-out 盲评看到近同文本 → 平局 → 不计胜。各刷分通道两两互堵。

## 逐条回答简报的问题 1–5

**问 1(循环站得住吗;"证据不足"怎么办)**:骨架站得住,但只在"best-of-N + 条件精修"这个塌缩形态上站得住——预算算术不给"多轮自适应"留位置(B=3 至多 1 步,B=8 至多 3 步)。"证据不足-0.68"从会计角度是**精修惰性档**:它缺证据,而精修调用只能改措辞、不能制造证据,2 调用换约 0 期望增益,禁投。处理:(a) 终态化——0.68 不精修;(b) 若它是池最优且预算 ≥2,买**一次**保险宽步后停;(c) 出口侧用**探索槽**解决"这是产品最想要的产出"与"分数排不过 0.70/0.85"的矛盾:top-K 保留 1 席给最优的首裁-0.68-带证伪条件候选,0 调用成本;(d) B=8 时可选花 1 调用对其重裁一次,两次独立裁决同判"证据不足"算弱佐证——同源采样,相关性高,只当噪声过滤用,别当确证。提高对它信心的机械办法在循环内不存在,存在于循环外:时间前瞻复核。

**问 2(收敛判据)**:"连续两轮无更优"应删除。B=3 触发概率 = 0(②节结构性证明);B=5 只能与预算耗尽同时触发,节约恒 0;B=8 至多省 2 调用,却先烧 4 调用确认轮,且在 best=0.85 时因封顶退化为"必烧 4 调用的税"。替代:天花板停(0.85 即停,负成本)+ 预算停 + 两个徒劳停。全部机械、不依赖模型自评,且每条的触发都写明省了几次调用,可审计。

**问 3(越修越空)**:风险真实,且量表结构恰好补贴它:从尖锐主张软化措辞,是 严重→轻微→无法反驳 的最省力爬升路径(全空会掉进致命-0.00,但**半空**是甜点区)。不能用"具体度评分"当门——那就是简报铁律里被刷烂的量化论断计数的转世。机械挡板用**非对称棘轮**(0 调用):精修结果若丢失 parent 的任一{数字、命名实体、可证伪条件},机械拒收,保留 parent,ledger 记棘轮拒收。非对称性是关键:棘轮只罚删除、不奖添加,往候选里塞数字**得不到任何分**,所以它不构成可刷代理。残余风险(保留数字但把周边论断说软)如实承认,由 held-out rubric 在评测端兜底。

**问 4(同源盲区)**:循环内修不起——异源裁决使每候选成本从 2 涨到 3,B=3 下候选数从 3 掉到 2,先亏 33% 的池宽度去买不确定的去偏。会计答案:(a) 循环内接受盲区,但**禁止精修 0.85**(本设计已内建)——简报担心的"加倍投入"通道被这一条掐断,循环对盲区的暴露度回落到与 best-of-N 完全相同(都只是"选它当冠军"),循环不更差;(b) 循环外,20% 抽样运行对冠军做 1 次异源 held-out 复裁,统计降档率,预注册报警线(如被审 0.85 中 >30% 被降档 → 冻结天花板停、触发 critic 校准),这是监控指标,不是门;(c) 长线由时间前瞻复核兜底。

**问 5(凭什么证明优于 best-of-N)**:见 ⑤ 节完整设计。直说结论:按现有证据(深化夺冠 0/24、7/8 冠军是种子),第 0 段两道机械门大概率当场判死,那就**上 best-of-N,删循环,不丢人**——保留的三样东西(critic 裁决解析、去重、诚实台账)本来就与循环无关。条件精修作为 2 调用的末端期权,便宜到值得给一次预注册的受审机会,但它的生死由 p̂ 对 q̂85 的比较和 held-out 配对胜率决定,不由架构审美决定。**证明不了 = 默认 best-of-N**,这条判定规则连同阈值一起预注册,免得到时候舍不得。

## 铁律检验:我自己的判据可不可以被"说空"或"多生成几条"廉价满足

| 判据 | 廉价满足路径 | 后果与挡板 | 裁定 |
|---|---|---|---|
| 天花板停(0.85 即停) | 半空措辞骗到 0.85 | 停止是省钱不是奖励——刷成功的收益是"少花调用",不产出更多产物;评测端 held-out + 抽审降档率兜底 | 风险中,可承受 |
| 深仅在 0.70 | 生成器无法自选裁决档位 | 同源合谋归问 4,由抽审监控 | 通过 |
| 宽在全池致命 | "多生成几条"正是其本意 | 去重 + 连续 2 次徒劳停,烧钱有上限 | 通过 |
| 0.45→0.68(补一句证伪条款 = +0.23) | **全系统最可刷的一格** | ledger 打 clause-added 标;评测不计胜;探索槽只认首裁 0.68 | 已围堵,承认是量表固有弱点 |
| M0b 冠军身份率 | 精修产出近重复躲过去重 | held-out 盲评见近同文本 → 平局 → 不计胜,闭环 | 通过 |

总裁定:唯一结构性可刷点是量表自带的 0.45→0.68 条款附加,已在台账与评测两层拔掉其收益;其余判据要么触发即省钱(刷之无利),要么有机械闭环。**没有任何一个"往深/往宽/停止"判据在被廉价满足时能换来更多产出或更高评测分**——刷分通道的出口全部接在"少花钱"或"不计胜"上。
