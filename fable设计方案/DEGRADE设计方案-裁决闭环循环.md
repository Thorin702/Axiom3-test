# DEGRADE 最终设计:种子优先 best-of-N + 单事件机械停止 + 预注册精修期权(默认关闭)

> 对应简报:《DEGRADE设计简报-loop方案.md》。本文是唯一交付方案,可直接实现。

---

## 0. 摘要(方案一句话 + 关键决策)

**一句话:砍掉整棵 AB-MCTS;产线默认部署"种子优先 best-of-N"——先半价裁决完免费种子,种子耗尽后按确定性决策表补宽,四个单事件机械停止,诚实台账;"针对最强反驳的一遍精修"降级为默认关闭的配置期权,用处死树的同一把尺子受审,赢了才开。**

关键决策:
1. **支配性引理定序**:存在未裁决种子时,1 调用的种子裁决严格支配一切 2 调用动作;宽步只在种子耗尽后允许。
2. **"连续两轮无更优"处死**(B=3 触发概率恒 0,结构性证明);停止 = 天花板 / 预算 / 宽步徒劳 / 前沿,全部单事件、裁决触发。
3. **精修默认 OFF**:0/24 实测把举证责任压给精修;两道机械门 + 预注册 held-out 配对实验(约 116 题、1856 调用,价签先写死)定生死。
4. **0.68(证据不足)终态化**:永不精修;先裁完免费种子,至多一次保险宽步,然后单列"探索性前沿"轨道输出,不挤占站住候选席位。
5. **防空泛如实交底**:元素棘轮与旧反驳封顶是机械的,但只护精修边;新鲜候选的底线是同源 critic 的刻度——单点依赖,由离线三层(抽审/held-out/时效复核)监控,不假装存在全机械防线。
6. **指标分四类如实标注**:真零模型的指标不测质量,测质量的指标离不开模型;不存在两全,本文不宣称两全。

## 1. 裁定:循环 vs best-of-N(先给结论,再给设计)

实测数据:24 次扩展中"加深"候选合法夺冠 **0 次**;8 题中 **7 题冠军是初稿种子**(冠军非种子率 12.5%)。

诚实读法分两层:

- **0/24 没有在数学上判死"裁决制导的定向精修"。** 那 24 次发生在 Thompson≈抛硬币的无靶点乱修之下;rule-of-three 给出 95% 置信上界 ≈0.125,且 0/24 与 p=0.10 相容(P(0/24 | p=0.1)≈8%,并不"极低")。定向精修(最优者 + critic 点名的反驳 + 棘轮门)是另一个策略,旧数据约束它、但没有测过它。
- **但 0/24 足以决定默认值。** 在唯一实测证据全部指向"方差在第一稿、不在精修"时,把 2 调用的定向精修放进默认在线行为、再等实验来关掉它,是举证顺序颠倒。正确顺序:**精修默认关闭,先证明、后上线。**

因此最终裁定,明确写下:

> **先上 best-of-N。** 产线默认形态 = 种子优先 best-of-N + 单事件机械停止 + 异源复核 + 诚实台账(第 2–6 节)。
> **精修(含锐化)是默认 OFF 的配置期权**(第 7 节),完整规格随本文交付,但只有先后通过第 9 节的两道机械门与预注册 held-out 配对实验,才允许在配置层打开;任一环节不过,期权永久停留在 OFF。
> 循环唯一说对的事照单全收:树的罪是"假装用信号决策"。本方案把它兑现在控制器上——**每一步动作都是裁决档位的确定性函数**(第 5 节决策表),可用反事实重放机械证明"信号在开车"(M-A1)。但"信号驱动"≠"迭代精修划算":在 3–8 调用的世界里,信号驱动的主要用途是**省钱(早停)与定序(先买便宜的分数)**,不是雕琢。

## 2. 预算会计(其余一切的地基)

严格计数一切 LLM 调用:生成 = 1,裁决 = 1,重裁 = 1,复核 = 1。原子成本单位:**新候选 = 生成 + 裁决 = 2**。

**制度甲(默认)**:初稿种子由上游产出,生成成本沉没,种子只付裁决费 **1 调用/条**——这是全系统唯一的半价通道。
**制度乙**(种子也计费):不存在半价通道,方案退化为"槽位加宽的纯 best-of-N":W = floor((B − r_x)/2) 条新候选,余数走尾检规则;其余机制不变,不再单列。

### 2.1 动作价目表

| 动作 | 成本 | 说明 |
|---|---|---|
| `JUDGE_SEED` | 1 | 裁决一条未裁决种子(半价) |
| `REJUDGE` | 1 | 裁决未解析时的重裁;仅从解析失败路径可达,每候选 ≤1 次 |
| `FRONTIER_XCHECK` | 1 | 尾余 1 调用时,对首裁 0.68 候选做一次异源复核(min 合并) |
| `CROSS_EXAM` | 1 | 对最终冠军的异源复核;仅 B≥6 预留 |
| `WIDEN` | 2 | 携带角度排除清单 + 槽位分派,生成新候选并裁决 |
| `REFINE` / `SHARPEN` | 2 | 精修/锐化 + 裁决;**仅启用态存在**(第 7 节);棘轮拒收时只花生成的 1 调用 |

### 2.2 会计恒等式与种子供给护栏

- 输入:B ∈ [3,8],s = 未裁决种子数(**外生变量,由上游决定,本方案不假设其范围**),K = 产物席位数(产品参数)。
- 复核预留:r_x = 1 若 B≥6,否则 0。
- **种子护栏(修复 s>B 超支)**:N_j = min(s, B − r_x),按初稿输出顺序取前 N_j 条(确定性、可审计);其余种子不裁决、不入池、不参与排序,台账记「未裁决种子 ×(s−N_j)」。没有分数的候选永不进产物。
- 宽步上限:W_max = floor((B − r_x − N_j) / 2)。
- **不变式**:Σ(动作成本) + r_x 实际花费 = B − b_剩,台账逐条核对,并在产物中打印。

**s 是决定实际轨迹形态的第一变量**:s ≥ B − r_x 时方案自动塌缩为"纯种子裁决 + 复核"(这是特性不是故障——便宜的分数买不完时,不该买贵的);s 很小时宽步才登场。下表的"形态"是**状态的涌现结果,不是排程**,一切以第 3 节控制流为准。

### 2.3 各 B 静态配置与示例轨迹(逐步计数)

| B | r_x | REFINE_CAP(仅启用态) | s ≥ B−r_x 时的形态 | s < B−r_x 时的形态 |
|---|---|---|---|---|
| 3 | 0 | 0 | 裁 3 条种子 | 裁 s 条 + 宽 ×W + 尾检 |
| 4 | 0 | 0 | 裁 4 | 同上 |
| 5 | 0 | 1 | 裁 5 | 裁 s + 宽 ×W + 尾检 |
| 6 | 1 | 1 | 裁 5 + 复核 | 裁 s + 宽 ×W + 尾检 + 复核 |
| 7 | 1 | 1 | 裁 6 + 复核 | 同上 |
| 8 | 1 | 2 | 裁 7 + 复核 | 同上 |

示例轨迹(默认态,逐步验算):

| 场景 | 轨迹 | 计数 |
|---|---|---|
| B=3, s=4 | J,J,J;第 4 条种子入账"未裁决" | 3 = B ✓ |
| B=3, s=2 | J,J;Q=∅ 余 1 → 尾检(若有首裁 0.68)或闲置入账 | 2–3 ≤ B ✓ |
| B=5, s=2 | J,J;WIDEN;余 1 → 尾检/闲置 | 4–5 ≤ B ✓ |
| B=8, s=3 | J,J,J;WIDEN;WIDEN;CROSS_EXAM | 3+4+1 = 8 ✓ |
| B=8, s=3,首条种子 0.85 | J(0.85)→ 天花板分支:补裁 J,J 至 K 席或 Q 空 → 停;CROSS_EXAM | 4 ≤ 8,省 4 ✓ |

### 2.4 墙钟(如实,不缩水)

并行波次:种子裁决 1 波;宽步 = 生成 1 波 + 裁决 1 波;复核 1 步。默认态串行深度 ≤ 4 个调用时长(2–6 分钟);启用精修后每次精修 +2 个串行时长。**"BoN ≈ 2 个调用时长"只对纯种子形态成立,触发宽步/精修时分别约 4 / 6 个串行时长——双账本(调用数 + 墙钟)分臂如实入台账,不许只报好看的那本。**

## 3. ① 控制流(伪代码,逐行调用计数)

```text
输入: seeds[](顺序冻结), B∈[3,8], K, 证据集 E, 角度槽位表 ANGLES
配置: REFINE_ENABLED = false          # 默认;仅第 9 节实验全过后允许置 true
状态: pool=[], ledger=[], b = B − r_x, r_x = (1 if B>=6 else 0)
      insurance_used=false, futile_wides=0, spent=0

Q = seeds 的前 min(|seeds|, B−r_x) 条            # 种子护栏;其余入账"未裁决"
loop:                                            # 不变式:每次迭代要么花费 ≥1 调用,要么 break
    # —— 行 0:预算地板 ——
    if b == 0: STOP(S3 预算耗尽); break

    # —— 行 0.5:空池守卫(pool=∅:首轮、s=0 或产物全被弃置;保证行 1 起 pool≠∅)——
    if pool == ∅:
        if Q≠∅: JUDGE_SEED(Q.pop()); continue    # 1 调用,与行 3 同义,提前拦住行 1 的 max_score
        if b < 2: ledger 记「余 1 调用无可用动作」; STOP(S3); break
        if futile_wides >= 2: STOP(S4 宽步徒劳, 打「无存活候选」旗); break
        WIDEN(带角度排除清单); continue           # 2 调用;空池视同致命档走宽

    # —— 行 1:天花板分支(池内存在 0.85)——
    if max_score(pool) == 0.85:
        if |pool 中 ≥0.70 者| < K and Q≠∅:
            JUDGE_SEED(Q.pop())                  # 1 调用;只许半价补 K 席,禁一切 2 调用动作
            continue
        STOP(S1 天花板); break

    best = argmax_score(pool)                    # 平分:创建更早者胜(禁任何计数型 tie-break)
    # —— 行 2:解析失败重裁(仅此路径可重裁,≤1 次/候选)——
    if best.pending_rejudge:
        REJUDGE(best)                            # 1 调用;仍未解析 → 终态 0.50T,打旗
        continue
    # —— 行 3:支配性引理 ——
    if Q≠∅:
        JUDGE_SEED(Q.pop())                      # 1 调用;半价买分数,严格支配一切生成
        continue
    # —— 行 4:尾余(Q=∅ 且 b==1)——
    if b < 2:
        if ∃首裁0.68候选 x and 尾检未用: FRONTIER_XCHECK(x)   # 1 调用;分=min(两裁)
        else: ledger 记「余 1 调用无可用动作」
        STOP(S3); break
    # —— 行 5:裁决档位 → 动作(Q=∅, b≥2;穷尽 switch)——
    switch level(best):                          # 行 0.5 已保证 pool≠∅,best 必存在
      case 0.70(轻微):
          if REFINE_ENABLED and refines < REFINE_CAP[B]: REFINE(best)   # 2 调用(棘轮拒收时 1)
          else: WIDEN()                                                  # 2 调用
      case 0.68(证据不足+可证伪):
          if REFINE_ENABLED and best.血统未锐化: SHARPEN(best)           # 2 调用
          elif not insurance_used: insurance_used=true; WIDEN()          # 2 调用,一次保险
          else: STOP(S2 前沿); break
      case 0.85: unreachable(行 1 已拦)
      case 0.00 / 0.35 / 0.45 / 0.50T(重裁后终态,按 0.45 处置):
          if futile_wides >= 2: STOP(S4 宽步徒劳, 打「无存活候选」旗); break
          WIDEN(带角度排除清单)                   # 2 调用
      default: STOP(S5 兜底, 记录未匹配状态); break   # 防零消耗死循环:switch 必穷尽
    continue

# —— 收尾 ——
if r_x == 1 and pool≠∅: CROSS_EXAM(champion)      # 1 调用;终分 = min(本源, 异源);复核类型必标注
finish():
    站住轨: 按终分排 top-K;每条带裁决档标签;分 < 0.35 强制标注「未站住」
            若全池 < 0.35 → 产物如实输出「本轮无站住候选」+ 最高分者带旗,不装
    前沿轨: 至多 1 席;条件 = 首裁 0.68 ∧ 证伪条件非空 ∧ 非 clause-added
            标注「探索性前沿 | 未验证 | 同源裁决」;不挤占站住轨席位;进入时效复核清单
    台账全量落盘 + 打印会计不变式与停止原因码
```

辅助语义:
- `WIDEN`:从 ANGLES 选与池内候选 3-gram Jaccard 最小的未用槽位生成,prompt 附角度排除清单;裁决入池;去重(G1)弃置不退预算。WIDEN 后若全池仍 ≤0.45 则 futile_wides += 1,否则清零。
- `JUDGE_SEED / WIDEN` 产物的裁决未解析 → 先本地正则重解析(0 调用)→ 仍失败置 pending_rejudge(行 2 走 1 次 REJUDGE)→ 仍失败 = 终态 0.50T 打旗。
- `REFINE / SHARPEN` 完整语义见第 7 节;默认态这两个分支不存在。

## 4. ② 停止条件

### 4.1 先处死"连续两轮无更优"

**命题:B=3 时触发概率恒等于 0,与分数分布无关。** 触发需要 best 确立后再完成 2 个完整轮(每轮 = 生成+裁决 = 2 调用,共 4),外加至少 1 调用先裁出 best:4+1=5 > 3。∎

| B | 触发可能性 | 相对"预算耗尽即停"的节约 |
|---|---|---|
| 3 | 0(结构性) | 0 |
| 5 | 仅与预算耗尽同时 | 0 |
| 8 | 可能 | ≤2 调用,且以先烧 4 调用"确认轮"为代价 |

更糟的是与封顶量表的病态交互:best=0.85 后"更优"在数学上不存在,该判据退化为"必烧 4 调用的税"。简报的怀疑不仅成立,而且低估了:它在 B≤5 下**恒等于**固定跑满。**删除,不留变体。**

### 4.2 替代:五个单事件停止(零耐心计数,零模型自评)

| 码 | 条件 | 成本性质 |
|---|---|---|
| S1 天花板 | 池内出现 0.85(补齐 K 席的半价裁决后) | 负成本:当场省下全部剩余贵动作 |
| S2 前沿 | best=0.68 ∧ Q=∅ ∧ 保险宽步已用(启用态还需锐化已试) | 结构上保证:免费种子未裁完时**不可能**触发 |
| S3 预算 | b=0,或 Q=∅ ∧ b<2(尾检后) | 地板 |
| S4 宽步徒劳 | 连续 2 次宽步后全池仍 ≤0.45 | 止损 + 打「无存活候选」旗 |
| S5 兜底 | switch 未匹配任何状态 | 防零消耗死循环的机械保险,触发即记异常 |

停止原因码入台账与产物。这些条件全部由对抗 critic 裁决的机械解析触发——"不依赖模型自评"禁的是生成器给自己打分,不是对抗裁决通道;但必须说清:**裁决本身是模型行为,停止条件的"机械"指触发逻辑,不指事件源**(全文同此口径)。

## 5. ③ 宽/深由什么信号驱动

**由裁决档位 × 预算状态 × 种子供给的确定性决策表驱动**(第 3 节行 1–5 即该表),不含 Thompson、不含任何抽样、不含模型自评。逐档定价:

| best 档 | 动作(默认态) | 会计理由 |
|---|---|---|
| 存在未裁决种子(任意档) | 裁种子 | 支配性引理:2 调用买 2 个分数 vs 买 1 个,严格支配 |
| 0.85 | 半价补 K 席后停 | 封顶,任何贵动作期望增益 = 0;**永不精修 0.85**(启用态同样禁止) |
| 0.70 | 宽(启用态:精修,CAP 内) | 宽的期望 = q85×0.15/步;精修的期望 = p×0.15/步 |
| 0.68 | 一次保险宽步 → 前沿停 | 精修改不出证据;0.68 是精修惰性档 |
| 0.50 | 本地重解析 → 1 次重裁 → 终态按 0.45 | 1 调用买最便宜的信息;禁为解析失败花 2 调用 |
| 0.45 / 0.35 / 0.00 | 宽(限连续 2 次徒劳停) | 修大缺陷 = 重写 = 宽的贵版;死马不医 |

**"往深"的全部价值被压缩为单参数问题**:唯一有意义通道是 0.70→0.85(+0.15),概率 p。种子耗尽后深优于宽 ⇔ p > q85;种子未耗尽时门槛翻倍(p > 2·q85),而此时决策表根本不给深/宽出场。p 与 q85 由台账免费累计(每次精修的前档→后档、每条新鲜候选的档位),使"要不要开精修"从架构信仰变成可测参数比较——这正是第 7 节杀开关与第 9 节实验的数据源。

现有证据:p 点估计 = 0(0/24),q85 > 0(实测有种子直接拿 0.85)。**这就是精修默认 OFF 的全部理由,一行台账就能推翻或坐实它。**

## 6. 机械挡板与诚实台账

挡板总原则:**一律单向否决或封顶,绝无加分项**。否决型判据"多做坏事被拦",加分型判据"多做样子得分"——被"量化论断计数"惨案击中的是后者,本方案在结构上不含这一类。

- **G0 单掷铁则**:每候选一生只被主 critic 裁决一次;唯一例外是解析失败路径的 ≤1 次 REJUDGE(失败的解析不是分数,重裁不是重掷)。若任何候选因复核等原因存在多个已解析裁决,**记账取 min,永不取 max**——合并只降不升,结构上不可刷。
- **G1 去重(仅宽步)**:与池内任一候选内容词 3-gram Jaccard > 0.8 → 弃置,浪费 2 调用入账不退。**如实定位:词面去重只是防复制粘贴的地板,拦不住语义换写**;但骗过它不获得任何排名收益,只烧自己的预算,且被浪费率指标计入。N_eff 因此只作展示统计,不作门、不单独裁决任何消融。
- **G2 元素棘轮(仅精修/锐化边,0 调用,裁决前执行)**:见第 7 节 R1/R2。
- **G3 旧反驳字段(仅精修边)**:见第 7 节。
- **G4 血统上限**:每候选被精修 ≤1 次;链深上限 = 1(B≤7)/ 2(B=8,启用态)。同时是同源盲区的结构性资金上限:任何单血统最多吸 5 调用。
- **G5 "无法反驳"降级门**:裁决 = 无法反驳必须附结构化"已尝试攻击"非空清单,否则机械降级为证据不足档(按证伪条件有无取 0.68/0.45)——"攻不动"与"没攻过"不许同分。**如实声明:非空检查只是地板,清单内容由同一 critic 生成、可被敷衍填充,本门的实际强度取决于 critic 质量,不设内容门(那会是又一个粗糙代理)。**
- **G6 异源复核(B≥6)**:对最终冠军 1 次复核,终分 = min(本源, 异源)。**复核类型必须入台账与产物元数据:「异模型」或「同模型换人设」——后者对共享权重盲区的去相关能力接近零,不得标榜为"异源验证"。**
- **台账字段全集**:每调用 {序号, 类型, 目标, 槽位, 裁决原文+解析结果, 各门判定, 棘轮/去重弃置原因, softening 旗, rejudge 旗, 剩余预算},停止原因码,冠军血统,复核类型,p̂/q̂85 累计,单掷审计位,会计不变式核对行。产物打印摘要:宽/深各几步、浪费调用、冠军是种子还是精修产物、是否经真异源复核。

**防空泛的诚实交底(直答"有没有机械挡板")**:完全机械的防空泛挡板**不存在**。机械的只有两类——G2 棘轮(防"删着说空",只护精修边)与 G3 封顶(防"挪走主张涨分")。新鲜种子和宽候选没有任何运行时机械挡板,它们的底线是 critic 刻度里"空泛到不可检验 = 致命 0.00"——这是**模型判断**,且与唯一排序信号同源:**同一个 critic 既是排序信号又是防空泛底线,这是本系统显式承认的单点依赖**。对它的监控全部在离线:20% 抽样异源复裁的降档率报警线(冻结 0.85 中 >30% 被降档 → 冻结天花板停、触发 critic 校准;抽审是离线监控,不占单轮预算,特此入账声明)、held-out rubric 明文惩罚空泛、时效复核慢真值。对冲词密度只做台账旗标,**永不做门**。

## 7. 精修期权(默认 OFF;完整规格,启用须过第 9 节)

**启用条件(先证明后上线)**:M0a、M0b 两道机械门全过 ∧ 预注册配对实验判胜(第 9 节)。任一不过 → `REFINE_ENABLED` 永久 false,本节代码路径不执行。

- **REFINE(仅 best=0.70 触发)**:2 调用 = 精修生成(prompt 附 critic 点名的最强反驳)+ 裁决。REFINE_CAP:B≤4 → 0,B∈[5,7] → 1,B=8 → 2。
- **R1/R2 元素棘轮(0 调用,生成后、裁决前;不过则弃子留父,只花 1 调用)**:
  - R1:子的可证伪条件条目数 ≥ 父,且父每条的锚点(证据 ID / 数字 / 实体)在子中仍出现;
  - R2:父的具体元素集 S(数字+单位、命名实体、日期、证据引用 ID,**按结构化字段逐字段正则提取**——候选是固定字段的结构化文本,字段级提取显著降低中英混排噪音,误拦样本入台账)满足 **S(父) ⊆ S(子),零删除、无"同类型替换"豁免**(替换豁免可被"删承重元素、换装饰元素"套利,故删)。添加自由且**不加分**。
  - 非对称性是关键:只罚删除、不奖添加,塞元素得不到任何分,故棘轮自身不构成可刷代理。误拦的代价 = 浪费 1 调用,父本无损。
- **G3 旧反驳字段**:子的裁决 prompt 附父的最强反驳,critic 必须输出 `旧反驳: 已解决|仍成立|不再适用`(机械解析;**字段缺失或未解析一律按"仍成立"保守处理**)。子入池分 = min(自身档位分, 封顶):`仍成立` → 封顶父分−0.01;`不再适用` → 封顶父分 + softening-suspect 旗;`已解决` → 无封顶。子自身裁决走全七档正常映射;未解析走本地重解析→1 次重裁→0.50T。父本永不覆盖、永不删除,与子并存参与排序——精修最坏情形 = 浪费 2 调用,永不毁掉已有冠军。
- **合法夺冠定义(供 M2/M-A2 统计)**:子档位在格 `致命<严重<轻微<无法反驳` 上严格高于父 ∧ 旧反驳=已解决 ∧ R1/R2 通过。分数抖动不算改善;0.68/0.45/0.50 不在格上,永远不是精修对象。
- **SHARPEN(仅 best=0.68 触发,启用态)**:把证伪条件写得更具体可检验后再裁一次;每血统 ≤1 次(**血统级标记,锐化产物继承之,不得再锐化**);R1/R2 同样适用。二次裁决全档映射:升为 0.70/0.85 → 按相应行处理;降为 0.45/0.35/0.00 → 按弱档行;仍 0.68 → 前沿确认,待 Q=∅ 且保险宽步用毕后 S2 停;未解析 → 重解析→0.50T。经 SHARPEN 后仍 0.68 靠 clause-added 升到 0.68 的不存在(0.45→0.68 的升档打 clause-added 标,前沿席位与实验胜局均不认)。
- **全局杀开关(预注册)**:台账累计 30 次条件精修后,若 p̂ 的 Wilson 95% 上界 < q̂85 → 配置层永久禁用精修分支(0/30 上界 ≈0.10:只要新鲜候选有一成概率直接拿 0.85,深分支在期望上被支配)。

## 9. ⑤ 客观对照指标与实验设计

### 9.1 指标的诚实分类(先交底,再列表)

**不存在既零模型又测质量的指标。** 真零模型的指标(重放/账本类)只测"控制器是否用信号"与"钱花得冤不冤";一切测产出质量的指标都依赖某个模型的裁决。本文按四类如实标注,拒绝把"计算流程机械"偷换成"不依赖模型评判":

**类型一:真零模型(不测质量)**
- **M-A1 反事实重放**:把台账裁决序列打乱重放,统计动作序列改变率。树(Thompson,每臂 0–2 观测)≈不变;本方案 = 决策表的确定性函数,改变率高。机械证明"信号在开车"——这是控制器的离线性质,不可刷,但**任何裁决的确定性函数(哪怕坏函数)都满分,它不测产出好坏**。
- **M4 双账本**:调用数 + 墙钟,分臂物理量。
- **M-A4 浪费率**:去重弃置 + 解析失败烧掉的调用占比,台账直出。
- **M6 单掷审计位**:冠军得分从未受益于任何裁决重掷(布尔,台账)。

**类型二:冻结裁决协议下的机械计数**(计算机械、事件源是 critic;运行时不可见、不构成优化目标)
- **M0a p̂ 与 q̂85**:0.70→0.85 转化率 vs 新鲜候选直接 0.85 率,台账免费累计。
- **M0b 冠军身份率**:冠军 ∉ 种子集的比例(纯字符串比对)。现状 12.5%。
- **M2 合法精修夺冠率**:按第 7 节"合法夺冠"定义统计。
- 抽审降档率(离线,监控用)。

**类型三:held-out 异源盲评**(非自评、非运行时 critic;冻结 prompt+rubric 哈希预注册)
- **M1 配对冠军盲评**:不同模型家族、去臂标、随机左右序、rubric 明文惩罚不可检验的空泛。**方向性偏差如实声明:对运行内 critic 的优化会经共享权重部分迁移到 held-out 分数,偏袒精修臂;故 M1 永不单独定胜负,必须与类型一/二门联合判决,慢真值(M5)保留终审权。**

**类型四:慢真值**
- **M5 时效存活**:冠军的具体可证伪条件进入到期机械核对清单。慢,但这是系统里唯一不可刷的地面真值;凡宣称"可验证、有新意"的产品,必须建这条反馈,否则一切快指标悬空。

### 9.2 两段式验证(免费的门在前,贵实验在后)

**第 0 段:机械门(零评审成本,预注册阈值)**
- 门 A:累计 ≥30 次条件精修(影子模式/离线复跑产生,不动产线默认),p̂ Wilson 95% 上界 ≥ q̂85,否则判死。
- 门 B:触发精修的运行中 M2(合法精修夺冠率)≥ 25%,否则判死。树在 0/24 上被处死,精修用同一把尺子受审;现有数据当场不过——**这正是默认 OFF 的量化表达**。

**第 1 段:预注册配对实验(仅第 0 段全过)**
- **臂与会计(两臂总调用严格 = B,off-by-one 已修)**:取 s ≥ B 的题目;A 臂 = 裁决 B 条种子;B 臂 = 裁决 **B−2** 条种子 + 预留 2 调用,best=0.70 时做一次条件精修;**未触发则用预留补裁那 2 条种子 → 两臂逐字节相同 → 自动平局,不送评审,零成本**。(B−2)+2 = B ✓。
- **评判**:M1 盲评,每非平局对 1 调用。
- **主终点**:非平局对中 B 臂胜率;符号检验,单侧 α=0.05,H0: 胜率 ≤0.5。
- **功效与价签(预注册,防事后嫌贵偷工)**:检出胜率 0.70 需 37 个非平局对(0.65→67,0.75→23);按触发率 π=0.4、触发后平局率 0.2 计,约 **116 题 ≈ 116×2×8 = 1856 调用**。期中分析仅按预注册 O'Brien–Fleming 界;禁 optional stopping。
- **判定规则(预注册)**:同时满足 ①胜率 ≥0.65 且 p<0.05;②实验内 M2 ≥25%;③B 臂墙钟 ≤ A 臂 2 倍 → 采纳精修(REFINE_ENABLED=true)。**其余一切结果 → 维持默认 OFF。**
- **排除条款**:凡靠 clause-added(0.45→0.68 补条款)实现的升级,该对不计 B 臂胜局。
- **冻结与重审条款**:挡板定义、阈值与实验同版本冻结;改挡板 = 旧成绩作废、重新预注册重跑。**允许重审但不允许钓鱼**:每次重审须全新预注册且旧结果公开留档——既不给"调参重跑到显著"留门,也不用一次欠功效实验永久判死一个 2 调用的期权(功效已按上表预先算足,消除"程序性死刑"的偏袒)。
- **对自家增件同刻度**:消融 A1(角度槽位 vs 自由采样,比 M1 与浪费率)同规预注册,证明不了就删槽位,退到更朴素的形态。标准对双方同刻度。

### 9.3 不可刷性论证(如实版)

主终点 = 异源盲评配对偏好 + 两道类型二机械门;运行内 critic 分数不出现在任何终点。"多生成几条"在配对同预算下两臂同等受益;"把话说空"过不了 held-out rubric 且在精修边被棘轮拦截;精修产出近重复 → 盲评见近同文本 → 平局不计胜。**两处已知残余不装死**:①held-out 与运行 critic 共享权重的 Goodhart 迁移(方向偏袒精修臂,已声明,靠类型一/二门与 M5 对冲);②类型二指标的事件源仍是 critic(已如实分类)。

## 10. 简报"要你回答的具体问题"1–5 直答

**1. 循环站得住吗?"证据不足"怎么处理?**
循环在 3–8 调用下站不住,预算算术把它塌缩为"best-of-N + 至多 1–2 次条件精修":B=3 连一次 2 调用动作都排不进(裁 3 条种子已满),B=8 也只有 1–2 次出手。它唯一的真贡献——裁决制导的定向精修——用一个 2 调用的末端期权完整保留,不需要"循环"这个壳。
"证据不足 0.68":**接受即停,但停得有序**。(a) 没有任何额外调用能凭空造出证据,"再攻一次"在单掷铁则下是重掷刷分,禁;(b) 免费种子未裁完时不许停(S2 的触发结构上要求 Q=∅)——0.68 在手不构成放弃半价抽签的理由;(c) 种子耗尽后给一次保险宽步(新鲜抽签仍可能抽出 0.70/0.85);(d) 然后单列「探索性前沿」轨道输出:首裁 0.68、带证伪条件、非 clause-added,至多 1 席,强制「未验证|同源裁决」标签,不挤占站住轨。机械提高信心的办法:运行内只有异源复核取 min(尾检/G6;**如实承认:同源第二裁决对证据正交的候选无增信——它同样无据可攻**);真正的信心来源在循环外——时效复核。这是对新颖候选唯一诚实的信心来源。启用态另有 SHARPEN(把证伪条件磨尖后再裁一次)作为受审期权。

**2. 收敛判据?"连续两轮无更优"够吗?**
不够,而且是反面教材:B=3 结构性不可触发(4+1=5>3),B=5 恒与预算耗尽同时(节约恒 0),B=8 要先烧 4 调用确认停滞,还与封顶量表病态交互(0.85 后"更优"不存在,判据退化为纯税)。**删除。**替代 = 第 4 节五个单事件停止:全部由裁决档位或预算状态单事件触发,零耐心计数;S1 可在第 1 次调用就触发并省下全部剩余贵动作——"小预算下从不触发、退化为固定跑满"的指控对耐心计数成立,对单事件触发不成立。

**3. 精修会不会把候选越修越空?有没有机械挡板?**
会,这是精修最真实的失败梯度:存活分 = 抗攻击度,缩小可攻面的最省力方向就是软化,而"全空"掉进致命 0.00、"半空"是甜点区。机械挡板**存在但只护精修边**:R1/R2 零删除棘轮(只罚删除不奖添加,自身不可刷)+ G3 封顶("不再适用"=主张挪走,不涨分;"仍成立"=修了个寂寞,封顶父分−ε)+ 单轮 CAP(软化是复利过程,轮数封顶即有界)+ 父本保留(最坏浪费 2 调用)。**最强的挡板是默认 OFF:轮数=0**。同时如实交底:完全机械的防空泛挡板不存在,新鲜候选的底线是同源 critic 的刻度,单点依赖,由离线三层监控;对冲词表只做警报永不做门——为堵一个代理漏洞再造一个更糙的代理硬门,正是铁律禁止的事。

**4. 同源 critic 的共同盲区会被放大吗?**
迭代架构会放大(每轮精修都朝同源先验做梯度下降);本方案默认不迭代,盲区暴露度与朴素 best-of-N 相同(都只是"选它当冠军"),且**禁止精修 0.85**把"对盲区加倍投入"的通道彻底掐断(启用态同样禁止)。缓解(诚实版):G5 降级门("攻不动"须附已尝试攻击清单,否则降级——清单内容仍靠 critic,只是地板);G6 异源复核取 min(B≥6,1 调用买在边际信息最大的点上;**同模型换人设的去相关≈0,台账必须区分真异源/同源换装**);G4 单血统 ≤5 调用的资金上限;离线 20% 抽审降档率报警;M5 慢真值。**8 调用内无法根治——根治需要独立证据源或异构模型,超出本预算的世界;任何声称能在预算内解决同源盲区的设计都在撒谎。**

**5. 拿什么客观、不可刷、不依赖模型评判的指标证明优于朴素 best-of-N?诚实判断。**
诚实判断:**以现有证据证明不了,所以默认就是 best-of-N(种子优先版),本文整个架构就是这个裁定的兑现。** 0/24 与 7/8 指向"收益曲面在宽不在深"。精修唯一的翻案通道是第 9 节:两道类型二机械门(现有数据当场不过)+ 116 题预注册 held-out 配对实验,判胜阈值、功效、价签、冻结条款全部先写死;赢了才开,输了维持 OFF,重审须全新预注册。指标体系按四类如实标注(9.1),不把"计算机械"偷换成"零模型评判";真零模型的 M-A1/M4/M-A4/M6 锁死"控制器用信号"与"钱不冤",质量维度交给冻结计数 + held-out 盲评 + 时效存活,并公开声明各自的残余偏差。对自家增件(槽位)同刻度消融,证明不了就删——标准不双标。

## 11. 铁律检验(逐判据过)

> 铁律:一个不做真活也能满足的代理指标,一定会被不做真活地满足;绝不在粗糙代理上设硬门。
